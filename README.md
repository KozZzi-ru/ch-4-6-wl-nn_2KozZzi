## Автоматическая генерация SVG схем раскладки

Прошивка настроена на автоматическую генерацию визуальных схем раскладки клавиатуры при каждой сборке.

### Возможности

1. **Автогенерация SVG** - при компиляции автоматически создается SVG-схема раскладки клавиатуры
2. **Упаковка с прошивкой** - SVG-схема добавляется в ZIP-архив вместе с UF2-файлами прошивки
3. **Коммит схем** - сгенерированные схемы автоматически коммитятся в репозиторий в папку `keymap-drawer/`

### Артефакты сборки

При каждой сборке создаются 3 артефакта:

- **`keymap_raw_files`** - исходные SVG и YAML файлы схем раскладки
- **`firmware_BLK`** - UF2 файлы прошивки для левой/правой половины и settings_reset
- **`firmware_BLK_SVG`** - финальный пакет с прошивкой и визуальной схемой раскладки

### Конфигурация

- **`keymap-drawer/config.yaml`** - настройки визуализации (размеры клавиш, цвета, шрифты)
- **`config/charybdis.json`** - физическая раскладка клавиатуры (координаты клавиш)
- **`.github/workflows/draw_keymaps.yaml`** - reusable workflow для генерации схем
- **`.github/workflows/build.yml`** - основной workflow сборки с интеграцией SVG

### Кастомизация биндингов

В `draw_keymaps.yaml` настроен маппинг для специальных биндингов:
- Макросы трекбола (`&mkp LCLK`, `&mmv MOVE_UP`, `&msc WHEEL_UP`)
- Кастомные макросы (`&HSplit`, `&VSplit`, `&caps_word`)
- Фразы на русском языке

Для добавления новых биндингов отредактируйте `KEYMAP_raw_binding_map` в draw_keymaps.yaml.
